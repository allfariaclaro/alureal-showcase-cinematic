# Alureal Cinematic Showcase

Experimento visual conceitual para demonstrar direção de arte, movimento, profundidade e narrativa por scroll sem bibliotecas de runtime.

## Demonstra
- composição espacial em CSS;
- parallax orientado por scroll;
- interação com ponteiro;
- seções imersivas;
- responsividade;
- redução de movimento;
- GitHub Pages.

Este projeto funciona como showcase técnico e visual da Alureal.
